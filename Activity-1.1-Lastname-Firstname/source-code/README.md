# Pangasinan Heritage Digital Showcase

## Run locally
1. Install Node.js 18.17+ or a compatible Node.js 20 LTS environment.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Next.js.

## Build
- `npm run build`
- `npm start`

## Atomic Design
- Atoms: Button, Typography, ColorTokens, Icon, Image
- Molecules: HeritageCard, SearchForm, NavigationItem
- Organisms: HeritageGrid, HeaderNavigation

The project intentionally uses lightweight CSS and simple SVG placeholders to keep the showcase fast for mobile users.
